# User Stories Placements

- Als User will ich Deckenlampen nur auf der Decke platzieren können, woanders schaut es falsch aus. 

- Als User will ich Wandlampen nur an der Wand platzieren können, woanders schaut es falsch aus. 

- Als User will ich, dass das Gerät dort platziert wird, wo ich hin zeige. 

- Als User will ich sehen wo das Gerät hin platziert werden würde. 

- Als User will ich, das man den Garten Robo nur draußen am Boden platzieren kann, anders macht es keinen Sinn

- Als User will ich, das man den Staubsauger Robo nur am Boden platzieren kann, anders macht es keinen Sinn

- Als User will ich, Jalousine nur bei Fensteröffnungen platzieren können. 

- Als User will ich eine Art von Kamera haben die man an der Wand platzieren kann und noch eine Art die man an der Decke platzieren kann. 

- Als User will ich unter der Fensterbank eine Heizkörper platzieren können. 

# User Stories 

- Als User möchte ich mich im 3D Haus bewegen können, damit ich mir das ganze Haus frei anschauen kann.

- Als User möchte ich einen Tablet haben wo ich alles einstellen kann was ich brauche, damit ich es einfacher habe und alles in einen Gerät einstellen kann.

- Als User möchte ich einstellen können ob ich hintergrundmusik will und wie laut.

- Als User möchte ich das Tablet auf der rechten Hand haben und die virtuelle Hand auf der linken Hand und umgekehrt, damit ich für mich immer komfortable habe.

- Als User möchte ich eine App haben wo man Musik und was auf welche Hand ist, einstellen kann, damit ich das Programm so konfigurieren kann wie ich will. 

- Als User möchte ich, Die Temperatur, Uhrzeit sowie auch das Wetter selbst einstellen können, damit ich schnell weiß ob die Geräte so funktionieren wie sie konfiguriert worden sind. 

- Als User möchte ich jederzeit zur Anfangsscreen vom Tablett gehen könne, damit ich nicht immer auf zurück klicken muss. 

- Als User möchte ich eine App haben wo ich alle Kameras sehen kann die ich platziert habe, damit ich schnell Zugriff auf allen Kameras habe. 

- Als User möchte ich in die Kameras App die einzelnen Kamerabilder vergrößern, damit ich es besser sehen kann. 

- Als User möchte ich mit einen klick das Tablett wieder verkleinern und auf die Seite haben wie am Anfang.

- Als User möchte ich über eine App, mir alle die Devices sehen die ich platzieren kann und sie mit einen + im Haus hinzufügen, damit ich schnellen Zugriff auf die Geräte habe. 

- Als User möchte ich über eine App, alle Devices sehen die ich schon platziert habe, damit ich eine guten Übersicht über meine Geräte habe. 


# Userstorys Device Hub
- Als User möchte ich bei den Jalousien einstellen können Zu welcher Tageszeit sie ausfahren sollen, damit ich dies in zukünftigen tests nicht selber machen muss.
- Als User möchte ich bei den Jalousien einstellen können bei welchen Außentemperaturen die Jalousien hoch/runter fahren kann, damit es im haus nie zu warm wird
- Als User möchte ich das der Staubsaugerroboter automatisch den boden saugt, damit ich ihn nicht steuern muss 

- Als Nutzer möchte ich im "Device Hub" des Tablets eine Übersicht all meiner platzierten Geräte (z. B. "Bob's room light", "living room door light") sehen, um diese schnell auszuwählen oder bei Bedarf zu löschen.
- Als Nutzer möchte ich bei Lampen die Helligkeit und Farbe bzw. Farbtemperatur steuern sowie auf zuletzt verwendeten Farben zuzugreifen, um die Beleuchtung schnell anzupassen.
- Als Nutzer möchte ich bei der Heizung die Zieltemperatur über einen Regler (z. B. von 12,0° bis 22,0°) und den Modus (z. B. "Auto", "Heat") sowie die Lüftergeschwindigkeit (Fan Speed) einstellen, zusätzlich möchte ich noch die Ist-Temperatur sehen.
- Als Nutzer möchte ich die Live-Feeds und Aktivitäten meiner Kameras abrufen, um das Haus zu überwachen.
- Als Nutzer möchte ich bei Schalousien/Rollos den Zustand sehen und die Schalousien ganz öffnen/ganz schließen oder genau die Position einstellen können, um den Lichteinfall im Haus gezielt zu steuern.



Device Hub – Übersicht & Verwaltung

- Als Nutzer möchte ich die Device Hub auf meinem Tablet öffnen können, um eine Liste all meiner platzierten Smart-Home-Geräte zu sehen.
- Als Nutzer möchte ich in der Geräteliste den Namen und den zugewiesenen Raum des Geräts lesen können, um das richtige Objekt im Haus eindeutig zu identifizieren.
- Als Nutzer möchte ich jedes Gerät antippen und bearbeiten können, um das Gerät zu löschen und die spezifische Detail- und Einstellungsseite dieses einen Geräts bearbeiten zu können.
- Als Nutzer möchte ich nach dem Tippen auf den Mülleimer ein Pop-up-Fenster (z. B. "Are you sure you want to delete Bob's room light?") mit "Yes" und "Cancel" sehen, um zu verhindern, dass ich ein Gerät versehentlich lösche.

Allgemeine Detailansicht (Gilt für alle Geräte)

- Als Nutzer möchte ich am oberen Rand der Detailseite den Namen und Raum des Geräts (z. B. "Room Gerätename") sehen, um bestätigt zu bekommen, in welchem Menü ich mich befinde.
- Als Nutzer möchte ich einen "Zurück"-Button drücken können, um die Ansicht zu verlassen und zum Hauptmenü zurückzukehren.

Lichtsteuerung (Lampen)

- Als Nutzer möchte ich in der Licht-Ansicht auf einen Power-Button (Ein/Aus-Symbol) tippen können, um die Lampe direkt aus- oder einzuschalten.
- Als Nutzer möchte ich in der Licht-Ansicht einen Helligkeits-Button (Sonnen-Symbol) anwählen können, um Zugriff auf die Dimm-Funktion der Lampe zu erhalten.
- Als Nutzer möchte ich auf ein Farbrad tippen können, um eine exakte, stufenlose Farbe für meine RGB-Lampe einzustellen.
- Als Nutzer möchte ich in der Sektion "Zuletzt verwendet" auf bis zu 10 zuletzt verwendete Farben tippen können, um sofort zu meinen vorherigen Farben zurückzuwechseln, ohne das Farbrad neu einstellen zu müssen.

Heizung & Klima

- Als Nutzer möchte ich die gewünschte Zieltemperatur über einen kreisförmigen Slider (mit einem verschiebbaren Punkt auf dem Rand) stufenlos anpassen können, um das Raumklima grafisch und intuitiv zu regeln.
- Als Nutzer möchte ich die aktuelle Einstellung (z. B. "12,0° -> 22,0°") als Text in der Mitte des Sliders sehen, um den genauen Gradwert präzise ablesen zu können.
- Als Nutzer möchte ich die Temperatur über Plus- (+) und Minus- (-) Buttons in Einzelschritten verändern können, um eine feine Justierung vorzunehmen.
- Als Nutzer möchte ich in der Heizungs-Ansicht auf einen zentralen Power-Button tippen können, um das Klimagerät komplett ein- oder auszuschalten.
- Als Nutzer möchte ich über das Feld "Modus / Mode" (z. B. "Auto" oder "Heat") das grundsätzliche Verhalten der Heizung umschalten können, um sie an die Jahreszeit anzupassen.
- Als Nutzer möchte ich über das Feld "Fan Speed" die Lüfterstufe (z. B. mit Plus- und Minus-Buttons) regulieren können, um die Intensität des Luftstroms zu verändern.

Kameras

- Als Nutzer möchte meine Überwachungskamera (z. B. "front door cam", "garden cam") sehen, um den Videofeed zu sehen.
- Als Nutzer möchte ich in der Detailansicht einer Kamera eine Liste von "Aktivitäten" (z. B. "Person 23:00, 1 min") ablesen können, um nachzuvollziehen, wann Bewegungen in der Vergangenheit aufgezeichnet wurden.

Schalousien / Rollos

- Als Nutzer möchte ich in der Detailansicht der Schalousien einen Prozentwert (z. B. "50%") ablesen können, um den exakten Öffnungsgrad des Rollos zu überprüfen.
- Als Nutzer möchte ich auf einen "Open"-Button tippen können, um das Rollo automatisch komplett hochzufahren.
- Als Nutzer möchte ich auf einen "Close"-Button tippen können, um das Rollo automatisch komplett herunterzufahren.

# User Stories 3D

- Als User möchte ich mich in einen 3D Haus befinden, damit ich dort das Haus mit den Devices so gestalten kann wie ich will.
- Als User möchte ich dass am Anfang gleich ein paar basic Geräte im Haus platziert sind mit fertige Konfigurationen, damit ich einen leichten Start habe.
- Als User möchte ich alle Geräte die ich habe, über Device-Hub mit einen Button (select all) und dann Löschbutton, löschen kann, damit ich schnell ein leeres Haus habe und selbst die Geräte neu platzieren und konfigurieren kann.
- Als User möchte ich alle Geräte in 3D haben, damit sie zu den Haus passen und der Realität ähnlich sind.
- Als User möchte ich dass alle Geräte konfigurierbar sind, damit ich meine eigene Konfigurationen bei jeden Gerät haben kann in meinen Smart Home.
- Als User möchte ich dass sich das Wetter in der Umgebung ändert, damit ich weiß ob meine Konfigurationen funktionierten.
- Als User möchte ich im Haus Punkte am Boden haben wo ich mich hin teleportieren kann und sie sollen auch blinken, damit ich weiß ich kann mich genau dorthin teleportieren um mich im Haus zu bewegen.
